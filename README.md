# ParkEase – Smart Parking Management System

ParkEase is an AI-powered smart parking solution that detects vehicle occupancy using computer vision and provides real-time parking availability.

## Features

* Vehicle detection using YOLOv8
* Parking slot occupancy tracking
* Real-time availability monitoring
* Admin dashboard
* User dashboard
* Parking analytics
* Automated occupancy reports
* Image upload and processing

## Tech Stack

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* Python
* FastAPI

### AI/ML

* YOLOv8
* OpenCV

### Deployment

* AWS EC2

## Dataset

* Self-collected parking dataset
* Annotated using Roboflow
* 400+ parking images

## Results

* ~90% vehicle detection accuracy
* Real-time parking occupancy updates
